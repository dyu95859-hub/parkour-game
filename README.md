# 《墙影狂奔》

一款原创的浏览器横版跑酷小游戏：黑影在身后穷追不舍，跳过低栏和坑洞、滑过横杆；**每隔 10 秒**会出现一面墙，必须按提示做出指定动作才能冲过去。

**在线游玩：** https://dyu95859-hub.github.io/parkour-game/

## 操作

| 动作 | 键盘 | 手机 |
| --- | --- | --- |
| 跳跃 / 二段跳 | ↑ / W / 空格 | 上滑、轻点屏幕、↑ 按钮 |
| 滑铲（按住持续） | ↓ / S | 下滑、↓ 按钮 |
| 左 / 右（连招用） | ← → / A D | 左右滑、← → 按钮 |
| 破墙 | 空格 / X / J | “破”按钮、轻点屏幕 |
| 暂停 | P / Esc | 暂停按钮 |
| 音乐 / 音效开关 | M / N | 左上角按钮 |

## 墙壁动作

- **翻越**：快速连按两次 ↑
- **蹬墙**：按住 ↑ 不放（约 0.5 秒）
- **滑铲穿洞**：按 ↓
- **破墙**：按 空格 或 X
- **连招**：按顺序输入 3～4 个方向键（如 ← → ↑）

墙壁靠近时屏幕上方会显示动作提示和时机条，绿色区域即输入窗口。按错或没按会撞墙，黑影会大幅逼近。

## 技术说明

- 纯 HTML5 Canvas + 原生 JavaScript，无构建步骤、无外部依赖，本地直接打开 `index.html` 即可游玩。
- 所有画面由 canvas 绘制；所有音效和背景音乐均由 WebAudio 实时合成（原创旋律），不含任何外部素材。
- 最高分保存在浏览器 localStorage。
